TypeScript · numeric.js, rebuilt

Numerical analysis for JavaScript, with no eval.

numeric-2 brings numeric.js's linear algebra, complex numbers, sparse matrices, FFT, optimization, ODE solvers and splines to modern TypeScript. It never generates code at runtime, so it also runs on pages and platforms that forbid eval.

Read the API reference See the benchmarks

What it covers

Functional parity with numeric.js, reorganised into typed modules. Every function accepts plain arrays or numeric-2's tensor classes, and complex values work throughout.

Vectors, matrices and tensors

Real or complex data in Vector, Matrix and N-dimensional Tensor classes, with element access, blocks and in-place operations.

add · mul · exp · sqrt · sum · norm2 · iadd · getBlock · transjugate

Linear algebra

Products, solving, inversion, determinants and decompositions, for real and complex matrices.

dot · solve · LU · inv · det · eig · svd

Sparse matrices

Compressed-column storage with sparse arithmetic, products and an LU factorization for solving large sparse systems.

SparseMatrix · sparse.dot · sparse.lu · sparse.solve

Signal processing

Fast Fourier transforms of any length, not just powers of two, and linear convolution with NumPy's modes.

fft · ifft · convolve

Optimization

Unconstrained minimization with BFGS, plus linear and quadratic programming.

optimize.uncmin · gradient · solveLP · solveQP

ODEs and interpolation

Dormand–Prince integration with dense output and event detection, and cubic splines with derivatives and roots.

ode.dopri · interpolate.spline · Spline.at · Spline.roots

Random numbers

A seeded, NumPy-style generator for reproducible uniform, normal and integer samples of any shape.

defaultRng · uniform · normal · integers

Readable output

Every tensor, sparse matrix and result object prints as aligned columns, with long arrays summarized.

prettyPrint · toString

Why a rewrite

numeric.js is fast and broad, but it builds most of its functions with new Function while it loads.

Runs under a strict CSP

Pages whose Content Security Policy forbids unsafe-eval cannot load numeric.js at all. numeric-2 generates its kernels when the library is built, so it needs no runtime code generation.

Typed throughout

Written in TypeScript. Return types follow the arguments: a product of two matrices is typed Matrix, and a sample of shape [3, 4] is typed Matrix.

Checked against NumPy and SciPy

Over 1,500 tests, most of them comparing results with NumPy and SciPy on random inputs, from element-wise maths to eigenvalues, sparse solves and quadratic programs.

numeric.js bugs fixed

Among others: solveQP returning suboptimal or infeasible points, numerical gradients failing above 20 variables, spline roots going missing, and sparse matrices losing empty rows.

How fast is it?

numeric-2's speed relative to each library, as a geometric mean over the benchmark cases both support (1× means equal; above 1× means numeric-2 is faster).

Using it

The library is a single file with no dependencies. This site hosts the current build.

As an ES module

import { Matrix, linalg } from
  "https://stur86.github.io/numeric-2/dist/numeric-2.min.js";

Works in browsers, Node, Bun and Deno.

With a script tag

<script src="https://stur86.github.io/numeric-2/dist/numeric-2.umd.min.js"></script>
<script> const { linalg } = Numeric; </script>

Defines a global Numeric.

From source

git clone https://github.com/stur86/numeric-2
cd numeric-2 && bun install
bun run build    # → dist/

Builds ESM and UMD bundles, plain and minified.
